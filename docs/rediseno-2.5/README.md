# Documentación del rediseño LabelPrinter 2.5

Este directorio conserva el antiguo vault `LabelPrinter-2.5` dentro del repositorio único de LabelPrinter. «2.5» es el nombre de la línea de rediseño; el paquete de la aplicación conserva su versión `1.2.0`.

El código está en [`../../label-printer-web`](../../label-printer-web). En esta máquina, la raíz activa es `C:\Users\admin\LabelPrinter`. Empieza por [Inicio](00%20-%20Inicio/Inicio.md).

El registro original de cambios conserva su evidencia histórica. La versión consolidada del 10 de octubre de 2026 une los ajustes recientes con la búsqueda predictiva y las mejoras de impresión. Los documentos de planificación reflejan las decisiones y pendientes originales; el estado del código se verifica con `npm run verify` y las tareas de `odd/tasks/`.

La impresora de referencia del rediseño es Zebra GX420, a 203 DPI. La validación física de impresión y calibración sigue pendiente.
