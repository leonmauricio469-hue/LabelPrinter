# Zebra GK420t - Ficha Tecnica

## Especificaciones

| Caracteristica | Valor |
|---|---|
| Marca | Zebra |
| Modelo | GK420t |

|---|---|

## Caracteristicas Relevantes para el Proyecto

- **ZPL (Zebra Programming Language)** nativo
- Soporta impresion directa por USB (raw)
- Ideal para etiquetas de precio/retail
- Robusta para uso industrial continuo

## Configuracion Recomendada

| Parametro | Valor |
|---|---|
| Lenguaje | ZPL |
| DPI | 203 |
| Modo | Termica directa (papel termico) |
| Conexion | USB |

## Codigos de referencia

- ID Vendor (USB): `0x0A5F`
- ID Product: `0x0084` (varia por modelo)
- Puerto raw por red: `9100`
