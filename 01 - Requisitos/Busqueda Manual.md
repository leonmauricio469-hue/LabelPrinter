# Busqueda Manual

## Descripcion

Ademas del lector de codigos de barras, el sistema debe permitir buscar productos de forma manual.

## Tipos de Busqueda

### Por codigo
- Ingresar el codigo de barras a mano
- Util cuando el barcode esta danado o es ilegible

### Por nombre
- Ingresar texto y buscar coincidencias
- Util cuando no se conoce el codigo

## Ejemplo de Busqueda por Nombre

```
Buscar:
CAFE AMANECER

Resultados:
  CAFE AMANECER 250G
  CAFE AMANECER 500G
  CAFE AMANECER 1KG
```

## Prioridad

- **No es parte del MVP inicial**
- Funcionalidad complementaria
- Se implementa despues del flujo principal funcional
